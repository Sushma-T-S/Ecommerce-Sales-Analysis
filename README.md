# Ecommerce-Sales-Analysis
## Project Overview

Analyzed e-commerce sales data using Python, SQL, and Power BI to identify business insights and sales trends.

## Tools Used

* Excel
* Python (Pandas, Matplotlib)
* MySQL
* Power BI
* GitHub

## Key Findings

* Total Sales: ₹4.09 Million
* Total Profit: ₹509 Thousand
* Profit Margin: 12.42%
* Best Category: Office Supplies
* Best Region: East
* Top Product: Storage Box
* Highest Sales Month: April

## Dashboard Features

* KPI Cards for Sales and Profit
* Sales by Category
* Sales by Region
* Top Products Analysis
* Monthly Sales Trend

## Business Insights

The analysis showed that Office Supplies generated the highest revenue, East was the strongest performing region, and Storage Box was the highest-selling product.
